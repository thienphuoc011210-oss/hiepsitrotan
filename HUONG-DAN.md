# Hiệp Sĩ Tro Tàn - build APK
1. Tạo repo mới trên GitHub (Public), upload các file: index.html, icon-192.png, icon-512.png, package.json, capacitor.config.json.
2. Add file > Create new file, tên: .github/workflows/build-apk.yml, dán nội dung file build-apk.yml.
3. Tab Actions > Build APK (tự chạy sau khi commit). Đợi dấu xanh.
4. Mở lần chạy > Artifacts > tải Hiep-Si-Tro-Tan-apk > giải nén ra app-debug.apk > cài lên Android.
